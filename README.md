# منصة وفاء عمرو التعليمية

منصة رياضيات عربية باتجاه RTL مبنية بـReact وVite وTailwind CSS وFramer Motion، مع API بـPHP 8.2 وقاعدة MySQL/MariaDB عبر **MySQLi**.

## المتطلبات

- Node.js 20 أو أحدث وnpm.
- XAMPP يتضمن Apache وMySQL/MariaDB وPHP 8.2 بامتدادات `mysqli` و`mbstring` و`fileinfo`.

## إعداد XAMPP

1. شغّلي Apache وMySQL من لوحة XAMPP.
2. عند تثبيت جديد فقط، استوردي `database/schema.sql`. في قاعدة موجودة، استوردي `database/math_schema.sql` لإضافة الجداول والأدوار الناقصة؛ يستخدم الملف `CREATE TABLE IF NOT EXISTS` ولا يحذف بياناتك.
3. الاتصال الافتراضي يطابق XAMPP المحلي: `localhost`، المنفذ `3306`، المستخدم `root`، كلمة مرور فارغة، والقاعدة `wafaa_db`. غيّري القيم بواسطة متغيرات البيئة `DB_HOST` و`DB_PORT` و`DB_NAME` و`DB_USER` و`DB_PASSWORD` عند الحاجة، ولا تضعي بيانات الاتصال الحقيقية في الواجهة.
4. من مجلد المشروع نفّذي `npm install` ثم `npm run dev`. يمرر Vite طلبات `/api` و`/media` إلى Apache في `http://localhost/wafaaamro/`.
5. لإنشاء أول حساب مديرة مباشرةً، شغّلي الأمر التالي من مجلد المشروع. سيطلب الاسم والبريد وكلمة المرور مرتين، ويخفي إدخال كلمة المرور؛ لا يحتاج الحساب إلى التسجيل كطالبة أولاً:

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\database\create_first_admin.ps1
   ```

   يعمل الإعداد من CLI فقط ويرفض إنشاء مديرة ثانية. لحساب معلمة إضافي، أنشئي الحساب من صفحة التسجيل ثم شغّلي `C:\xampp\php\php.exe database\promote_teacher.php teacher@example.com teacher` مع استبدال البريد. لا توجد بيانات دخول افتراضية.

## الوظائف الحالية

- لوحة معلمة بإحصاءات وتقارير مستمدة من السجلات الفعلية فقط؛ لا تُنشأ بيانات إحصائية تجريبية.
- محرر للصفحة الرئيسية يتيح تعديل العناوين والعبارات والبطاقات، وإضافة منشورات ومشاريع كمسودات أو نشرها للزائرات.
- إدارة الصفوف والمجموعات والمواد والوحدات والدروس والمهارات، مع تسجيل الطالبات في المجموعات بواسطة البريد الإلكتروني وتعديل اسم الطالبة وبريدها وإعادة ضبط كلمة مرورها.
- شعار موحّد للمنصة، مع زر تبديل الوضع الداكن/الفاتح وحفظ الاختيار على الجهاز.
- بنك أسئلة يدعم الأنواع الستة، الصور حتى 5 MB، وKaTeX للصيغ المكتوبة بين `$...$` أو `$$...$$`.
- منشئ ألعاب بالقوالب العشرة، وتخصيص الأسئلة والوقت والترتيب وإعادة المحاولة.
- إدارة الواجبات والاختبارات وربطها بالصف أو المجموعة.
- مساحة طالبة للأنشطة والنتائج والنقاط والمستوى والتقدم والأخطاء والترتيب.
- التحقق من الأدوار في PHP، وجلسات HttpOnly، ورموز CSRF. تُحسب الدرجات في الخادم وتُحفظ محاولات الأسئلة لحماية سجل التقييم.

يتضمن المخطط الجداول المطلوبة، إضافة إلى `class_students` لربط الطالبات بالمجموعات، و`math_assessments` للواجبات والاختبارات، و`math_assessment_questions` و`math_attempt_questions` لحفظ أسئلة التقييم ونسخة المحاولة. حذف السؤال من البنك تعطيل آمن يحافظ على النتائج السابقة.

## API ومسارات التشغيل

واجهة الدخول والتسجيل: `api/index.php`. تعرض `GET site/homepage` محتوى الصفحة الرئيسية المنشور. تشمل مسارات الإدارة `teacher/dashboard` و`teacher/curriculum` و`teacher/questions` و`teacher/games` و`teacher/assessments` و`teacher/site-content`. يحدّث `PATCH teacher/students/{id}` بيانات الطالبة؛ وتبقى صلاحية المعلمة مقيدة بطالبات مجموعاتها. وتشمل مسارات الطالبة `student/dashboard` و`student/attempts`.

## البناء والنشر

- `npm run build` يبني ملفات الإنتاج في `dist/`.
- افحصي PHP باستخدام `C:\xampp\php\php.exe -l api\index.php`، وكرريه على ملفات PHP الأخرى بعد تعديلها.
- للنشر ضمن مجلد المشروع على Apache، انسخي محتويات `dist/` إلى الجذر مع الإبقاء على `api/` و`database/` و`.htaccess`. اضبطي بيانات قاعدة البيانات في بيئة الخادم واستخدمي HTTPS.
